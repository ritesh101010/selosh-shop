# The Selosh Soulpath

Mockup van een luxe webshop voor haarproducten en astrologie- en horoscoopproducten.

- `mockup.html`: de webshop-mockup (open via `index.html`)
- `hero-video/`: HyperFrames-compositie van de draaiende sterrenkaart in de hero
- `assets/`: gerenderde hero-video en productfoto's

Dit is een mockup. Merknamen en productfoto's zijn eigendom van de betreffende merken en worden alleen ter illustratie getoond; prijzen zijn indicatief.
